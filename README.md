# Azure AZ-104 Hands-On Portfolio

This repository documents 14 days of hands-on Azure labs completed while preparing for the
Microsoft AZ-104 (Azure Administrator Associate) certification. Each folder contains
screenshots, notes, and the actual CLI commands used to build, test, and tear down real
Azure resources across identity, storage, compute, networking, and monitoring.
